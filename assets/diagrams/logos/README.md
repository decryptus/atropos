# Diagram artwork

Atraxis and Auton symbols are copied from their existing ecosystem website assets.
Alertmanager uses the Prometheus flame: this vector comes from the official
`prometheus/prometheus` repository, `documentation/images/prometheus-logo.svg`
(blob `026f9e5bcc779247068b165976fd498d155ecf4b`).
See LICENSE-prometheus.txt for its Apache-2.0 license. Names and trademarks remain
with their respective projects; the diagram does not imply endorsement.

Atropos uses its original symbol beside a plain-text name, matching the other software.
Regenerate the diagrams with `python scripts/build_architecture.py`.
