# Atropos 1.0.5

The service now requires Sonicprobe 0.3.66. Sonicprobe adds missing `Date` and `Message-ID` headers to outgoing email while preserving headers supplied by the caller. This prevents rejection caused by missing message identifiers.

Engine and client versions are aligned at 1.0.5. No storage format or rule behavior changes are introduced.

The [qualification manifest](1.0.5-qualification.json) retains the prior bounded operational evidence and explicitly identifies its scope. Current package, SQL/TLS, recovery and image checks are required for this candidate; no new endurance or external email delivery evidence is claimed.
