# Atropos 1.0.6

Packaging maintenance release. The engine and client source distributions now contain only what is needed to build, install and run them: repository, test and maintainer files are no longer included. The wheels and the runtime code are unchanged apart from the version constants.

Engine and client versions are aligned at 1.0.6. No storage format, dependency or rule behavior changes are introduced.

The [qualification manifest](1.0.6-qualification.json) retains the prior bounded operational evidence and explicitly identifies its scope. Current package, SQL/TLS, recovery and image checks are required for this candidate; no new endurance or external email delivery evidence is claimed.
