# Atropos 1.0.3

The rule service uses HTTPdis 0.6.39. The request line and headers share a ten-second read deadline. The body gets ten seconds plus one second per 32 KiB, capped at 120 seconds. A client that trickles headers loses the connection. A slow body receives HTTP 408 before the command runs.

Install the new package or pull the 1.0.3 image and restart the service to pick up the change. Existing storage and configuration need no migration.

## Qualification

Loopback tests in the rebuilt image cover both expiry paths and a subsequent complete request. The same cases reproduced the issue with HTTPdis 0.6.34. The [qualification record](https://github.com/decryptus/atropos/blob/v1.0.3/docs/releases/1.0.3-qualification.json) separates this verification from the historical operational, recovery and endurance results.
