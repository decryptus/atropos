# Atropos 1.0.4

The service uses HTTPdis 0.7.1. Listeners use a default TCP backlog of 128. When upgrading a service that uses HTTP Basic authentication, replace legacy SHA-1 or DES htpasswd entries with supported hashes such as bcrypt before restarting.

The [qualification manifest](1.0.4-qualification.json) identifies the prior operational evidence and its scope. The release workflow verifies the current candidate and its package artifacts.
